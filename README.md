# GPC 3D Viewer (gpc-3d-viewer)

A Desktop GUI application for 3D visualization and analysis of GPC data using PyQt6 and PyQtGraph.

## 🚀 Features

- **3D Visualization**: Interactive 3D surface plots of chromatogram data.
- **Data Analysis**: Time slicing, Noise reduction, and Baseline correction.
- **Comparison**: Overlay multiple samples for comparative analysis.

## 🛠 Tech Stack

- **Language**: Python 3.10+
- **GUI**: PyQt6
- **Visualization**: PyQtGraph, NumPy, Pandas
